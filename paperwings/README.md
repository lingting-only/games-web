# 折纸空战 · Paper Wings

画在作业本上的折纸飞机空战。**点一下就飞，再点一下就把纸团扔出去** —— 不需要 WASD，也不需要鼠标锁定，鼠标和触屏都能玩。

和技术栈同门的《涂鸦街区》《涂鸦坦克》一样：纯静态站点，无构建步骤；画面里的一切（纸飞机、云、纸面、排线、8-bit 音乐）都是 three.js + WebAudio 程序化生成，没有图片、模型或音频文件。联机走 WebRTC 点对点（PeerJS），不需要游戏服务器。

## 运行

```bash
python serve.py 8912
```

打开 http://127.0.0.1:8912。部署到任意静态主机（Vercel、Netlify 等）即可联机游玩。

> 联机需要访问公共信令服务（PeerJS 云，默认 `0.peerjs.com`）。若所在网络无法访问，建房 / 加入房间会提示超时；单人飞行不受影响。

## 操作

| 动作 | 鼠标 / 触屏 | 键盘 / 手柄 |
| --- | --- | --- |
| 锁定敌机并自动投弹 | 单击敌机 | F（锁定最近目标）/ 手柄 A |
| 设置航点（飞机自动飞过去） | 单击空白天空 | — |
| 查看计分板（联机） | — | Tab / Create |
| 暂停 / 菜单 | — | Esc / Options |
| 音乐开关 | — | M |

纸团带重力，所以打移动目标需要提前量：屏幕上的橙色虚线就是预判弧线，锁定框标出目标。锁定后会按冷却自动连续投弹，点空白天空只改变航向、不会取消锁定。飞机始终自动向前盘旋，你的每一次点击都是一条指令。

## 玩法

- **单人飞行**：无尽波次。纸鹤（俯冲）、橡皮擦战斗机（耐打）、纸团投弹手（远程）逐波出现，每 5 波来一只巨型折纸鹤 Boss（撒纸屑弹幕）。每 5 波记下检查点，累计击落数解锁荧光笔涂装。3 条「折痕」耗尽即结算。
- **联机对战**：2–6 人自由混战，先到 10 分或 8 分钟结束；被击落后 2 秒带护盾重生。房主浏览器权威记分，每个人本地模拟自己的飞机并广播状态。支持公开房 / 私人房（5 位房间码）/ 快速匹配 / 中途加入 / 断线提示。联机模式是纯玩家对战，不生成 AI 敌机。

## 视觉

沿用 `doodleshooter` 的 `InkRenderer`：场景先渲进数据缓冲（明暗 / 墨色 id / 法线 + 深度），再由全屏 pass 画轮廓、排线、纸纹、横格线和红色装订线。墨色分工：

| 墨色 | 用途 |
| --- | --- |
| 蓝圆珠笔 | 玩家机、地面纸页线条 |
| 红笔 | 敌机、命中标记、被击落 |
| 石墨 | 折痕、尺桥、Boss |
| 橙荧光笔 | 预判弧线、锁定框、道具 |
| 粉色 | 橡皮擦战斗机 |
| 绿色 | 团队色 / 护盾 |

## 空域与场景

飞行区域为 `396 × 396`（初版 `132 × 132` 的三倍边长），高度 `9–52`；`sky.js` 里的 `MAP_SCALE = 3` 控制这个倍率。飞机以 60–115 单位的长航点直线飞行，并在到达边界 82% 之前就提前转向，避免小场地里不停绕圈。

纸面上的装饰全部程序化生成、用固定随机种子保证每次一致，并按墨色合并成少量 mesh（沿用 `doodleshooter/level.js` 的做法）以保持低 draw call：

- **可撞的实体**：18 张漂浮作业本页、3 座巨尺桥（带刻度）、7 座铅笔塔、9 块橡皮、6 个墨水瓶、8 组折纸山，均注册 AABB 碰撞体，纸团会被挡下。
- **纯装饰**：三层共 54 团揉皱纸云（缓慢漂移）、5 座纸风车（转动）、5 道回形针拱门、6 组便利贴方阵、4 圈橙色虚线航线、20 只高空纸鹤编队、14 处红笔批注（勾 / 波浪线 / 圈 / 星）、红笔太阳与光芒、装订孔、边界图钉与旗子。
- 12 个出生点分布在半径 95 的圆周上。

## 技术架构

```
paperwings/
├── index.html          # importmap(three) + peerjs + canvas#c + #hud + main.js
├── style.css           # 作业本风格 UI
├── serve.py            # 本地静态服务器
├── Dockerfile / docker-compose.yml
├── vendor/             # three.module.js + peerjs.min.js（与同门游戏一致）
└── src/
    ├── main.js         # 状态机、主循环、波次、大厅、计分、存档
    ├── render.js       # InkRenderer（原样复用，透视相机）
    ├── sky.js          # 三倍空域边界、文具装饰（按墨色合并几何）、碰撞体、出生点
    ├── plane.js        # 折纸飞机程序化几何 + 机翼扇动 + 涂装
    ├── flight.js       # 自动飞行：恒定速度、转弯半径、坡度、航点跟随
    ├── pointer.js      # 单击射线 → 目标 / 航点
    ├── projectile.js   # 纸团抛物线、提前量、预判弧线、命中判定
    ├── enemies.js      # 波次生成、三类敌机 AI、Boss、快照
    ├── players.js      # RemotePlane 状态编码与插值
    ├── effects.js      # 墨水迸溅 / 纸屑（复用）
    ├── physics.js      # AABB 射线（复用）
    ├── audio.js        # 程序化 8-bit 音乐音效（复用）
    ├── net.js          # PeerJS 大厅与消息层（复用，独立命名空间）
    ├── hud.js          # DOM HUD、菜单、大厅、结算
    └── util.js         # 小工具（复用）
```

联机消息：`hello / welcome / refused / lobby / startreq / start / ps`（20Hz 飞机状态）/ `fire`（纸团）/ `pdead` / `score` / `end` / `backtolobby` / `leave`。沿用原版做法：每个客户端本地模拟自己的飞机，命中由被击中者上报、房主统一记分。
