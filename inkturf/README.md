# 涂鸦圈地战 · Ink Turf

画在作业本上的圈地对战。**点一下纸面，笔尖小人就自动跑过去并留下一道墨线；把线画回自己的领地，圈住的那片纸就用排线涂满、归你所有。** 不需要 WASD，鼠标和触屏都能玩。

和同门的《涂鸦街区》《涂鸦坦克》《折纸空战》一样：纯静态站点、无构建步骤；画面里的一切（纸面、墨迹、排线、笔尖小人、8-bit 音乐）都是 three.js + WebAudio 程序化生成，没有图片、模型或音频文件。联机走 WebRTC 点对点（PeerJS），不需要游戏服务器。

## 运行

```bash
python serve.py 8913
```

打开 http://127.0.0.1:8913。部署到任意静态主机即可联机游玩。

> 联机需要访问公共信令服务（PeerJS 云，默认 `0.peerjs.com`）。若所在网络无法访问，建房 / 加入房间会提示超时；单人挑战不受影响。

## 操作

| 动作 | 鼠标 / 触屏 | 键盘 |
| --- | --- | --- |
| 移动并画线 | 单击纸面任意位置 | — |
| 暂停 / 菜单 | — | Esc |
| 音乐开关 | — | M |
| 重开本局 | — | R |

站在**自己颜色的领地**里点击才会开始画线；画线途中再点击只会改变去向，不会断线。回到自己领地时自动结算这次圈地。对手撞上你没闭合的墨线，线会被擦断，笔尖还会卡顿 1 秒。

## 玩法

- **单人挑战**：10 张手工纸面布局（墨渍、订书钉、尺桥、回形针框逐关增加），2–3 个各有分工的涂鸦怪。目标覆盖率逐关提高、可用时间逐关缩短，达成目标即解锁下一关；本地保存最高覆盖率与已解锁关卡。
- **联机对战**：2–4 人同场混战，90 秒结束时覆盖率最高者胜。房主浏览器权威模拟，客户端只上报点击意图。支持公开房 / 私人房（5 位房间码）/ 快速匹配 / 中途加入，随时查看右侧排行。

## 敌人 AI 与难度

涂鸦怪不是随机乱画，每次决策都在 `src/ai.js` 里跑一套轻量策略：

- **路线评估**：枚举以自己领地为角的若干矩形回路，按圈内的中性地、对手领地、障碍、路程成本以及对手距离打分，挑收益最高的一条。抢对手的地权重最高，所以你圈好的区域会被反吃。
- **预判拦截**：不追墨线的当前末端，而是沿对手剩余路径推算约 1 秒后的落点，只在自己来得及赶到时出击；长线优先、玩家优先。
- **风险规避**：发现自己未闭合的线末端附近有玩家时，立刻抄近路回家闭合，宁可要一小块地也不被整条擦断。
- **角色分工**：`expander` 大圈扩张、`hunter` 专盯切线、`raider` 盯着玩家领地抢。

难度按关卡线性升级：`skill = 0.34 + 关卡 × 0.075`（上限 1），影响反应冷却、拦截范围、回路尺寸与侵略性；AI 数量从第 1 关 2 个增至 3 个，AI 起始领地从 7×7 扩到 9×9、移速最高 23（玩家 19），目标覆盖率 `34% → 57%`，时间 `90 秒 → 70 秒`，障碍从约 353 格增至 460 格（设有硬上限，避免把纸面堵死导致寻路绕行）。被切线除了丢掉整条墨线，还会减速 1 秒；AI 寻路会绕开自己未闭合的墨线，玩家则仍可能自交。

## 规则细节

纸面是 `96 × 64` 的格子。一次闭合的判定是一次从纸面边界出发的 flood fill：

1. 把**自己的领地**、**自己未闭合的墨线**和**障碍格**临时当作墙；
2. 从四条边界做 4 连通 BFS，标记所有「从外面能到达」的格子；
3. 剩下够不到的格子（中性地或对手的地）全部划归自己，墨线本身也变成领地；
4. 若圈住的区域不足 3 格，这次墨线作废，不给分。

所以对手的地可以被吃掉，自己的地不会被重复计算。这套规则写在 `src/rules.js` 的纯函数里，单机 AI、本地玩家和房主模拟共用同一份代码。

## 视觉

沿用 `doodletank` 的正交俯视 `InkRenderer`（略带俯角）：场景先渲进数据缓冲（明暗 / 墨色 id / 法线 + 深度），再由全屏 pass 画轮廓、排线、纸纹、横格线和红色装订线。墨色分工：蓝圆珠笔 = 1 号玩家，红笔 = 2 号，绿笔 = 3 号，橙荧光笔 = 4 号，石墨 = 障碍与尺桥。领地用 `fill` 材质整片排线涂满，未闭合墨线是高出纸面的小方块，笔尖小人是一支倾斜的圆珠笔。

领地与墨线各用一个 `InstancedMesh`（每格一个实例），闭合时只更新变化的格子；障碍装饰按墨色合并成少量 mesh，整页保持个位数 draw call。

## 技术架构

```
inkturf/
├── index.html          # importmap(three) + peerjs + canvas#c + #hud + main.js
├── style.css           # 作业本风格 UI
├── serve.py            # 本地静态服务器
├── Dockerfile / docker-compose.yml
├── vendor/             # three.module.js + peerjs.min.js
└── src/
    ├── main.js         # 状态机、菜单、单机/联机、主循环、存档
    ├── render.js       # 正交 InkRenderer（复用 doodletank，frame 记忆纸面尺寸）
    ├── paper.js        # 96×64 栅格、领地/墨线实例化渲染、坐标换算、快照编解码
    ├── rules.js        # 纯函数：闭合 flood fill、覆盖率、BFS 寻路、栅格 RLE
    ├── authority.js    # 权威模拟：意图、逐格判定、事件流、增量/全量快照
    ├── actor.js        # 笔尖小人路径移动与逐格回调
    ├── ai.js           # 策略 AI：回路收益评估、预判拦截、避险与角色分工
    ├── layout.js       # 10 张纸面布局与障碍装饰
    ├── pointer.js      # 单击射线 → 纸面坐标
    ├── hud.js          # 覆盖率、计时、排行、菜单/结算
    ├── effects.js      # 橡皮屑 / 墨点迸溅（复用 doodletank）
    ├── audio.js        # 程序化 8-bit 音乐音效（复用）
    ├── net.js          # PeerJS 大厅与消息层（复用，独立命名空间）
    └── util.js         # 小工具（复用）
```

联机消息：`intent`（点击坐标）/ `snap`（15Hz，各笔尖位置 + 覆盖率 + 事件增量）/ `full`（中途加入的整页 RLE 快照）/ `start` / `end` / `backtolobby` / `leave`。事件增量只有四种：`trail`（新增墨线格）、`claim`（闭合占领的格子）、`cut`（线被擦断）、`owner`（初始领地）。整页状态只在有人中途加入时发一次。
