# 涂鸦坦克 (Doodle Tank)

画在作业本上的 90 坦克（Battle City）。蓝圆珠笔画的坦克、橙荧光笔砌的砖墙、手绘的老鹰基地 ——
守住你的老鹰，画掉每一辆敌军坦克。可以一个人闯关，也可以和好朋友联机双排守家。

和技术栈同门的《涂鸦街区》一样：整个游戏是纯静态站点，没有任何构建步骤；画面里的一切
（坦克、砖墙、纸面、排线、8-bit 音乐）都是 three.js + WebAudio 程序化生成的，没有一张图片、
一个模型或一段音频文件。联机走 WebRTC 点对点（PeerJS），不需要游戏服务器。

## 运行

```bash
python3 serve.py 8911
```

打开 http://127.0.0.1:8911。部署到任意静态主机（Vercel 等）即可联机游玩。

> 联机说明：浏览器之间点对点连接（WebRTC）需要访问公共信令服务（PeerJS 云，默认走
> `0.peerjs.com`）。如果所在网络无法访问它，创建/加入房间会提示超时 —— 换一个网络环境
> （或部署后在线上玩）即可；单人闯关不受任何影响。

## 玩法

- **单人闯关**：每关 22 辆敌军坦克从顶部三个出生点涌入（场上最多 5 辆），全部画掉即过关，
  共 10 张 21×13 宽屏手工地图，按由易到难排列（配合相机俯角正好铺满 16:9 屏幕），之后循环提速。
  基地老鹰被击毁或坦克打光即失败。
- **联机合作**：两人一队守老鹰。房主建公开房 / 私人房（5 位房间码）或快速匹配，客户端输入
  房间码加入。房主的浏览器负责模拟敌人与记分，每个人开自己的坦克。

### 地形

| 地形 | 特性 |
| --- | --- |
| 砖墙（橙） | 子弹可打碎，半格精度破坏 |
| 钢墙（石墨） | 只有满级坦克（3 星）的炮弹能击穿 |
| 河流 | 挡坦克，不挡子弹 |
| 树丛 | 遮住坦克，什么都不挡 |
| 冰面 | 坦克打滑，刹不住 |

### 道具（击毁闪红坦克掉落，共 9 种）

星（升级：双发 → 提速 → 破钢）、手雷（全灭场上敌军）、头盔（无敌护罩）、
铁锹（基地砖墙变钢墙，限时）、坦克（+1 命）、时钟（冻结敌军）、
速射（射击间隔大减，限时）、散射（一次三发平行弹幕，限时）、
穿甲弹（炮弹击碎砖墙后继续飞行，限时）。

## 操作

| 动作 | 键盘 / 鼠标 | 手柄 |
| --- | --- | --- |
| 移动 | 方向键 / WASD | 左摇杆 / 十字键 |
| 开火 | 空格 / J / 鼠标左键 | A / R2 |
| 音乐开关 | M | — |
| 菜单 | Esc | — |

主菜单可切换**视觉风格**：横线笔记本（原版墨水纸面）或纯色（平滑表面、无纸张线条）——
纯本地偏好，联机时只影响自己的画面，其他玩家可自行选择。

## 联机架构

和《涂鸦街区》同一套点对点方案：没有服务器，房主的浏览器就是权威。私人房占用一个随机
5 位码，公开房占住 PUB0..PUB15 槽位之一，快速匹配同时敲门所有槽位。房主以 15Hz 向客户端
广播世界快照（敌人、子弹、瓦片、道具、比分），客户端本地模拟自己的坦克并把开火命中、
砖块破坏上报给房主仲裁。

## 结构

```
index.html            极简壳：importmap + PeerJS + canvas + HUD
style.css             作业本纸面 UI
serve.py              本地静态服务器
src/
  main.js             引导、流程状态机、联机同步、主循环
  render.js           墨水渲染器（正交俯视 + 手绘后处理）
  physics.js          半格瓦片网格与碰撞
  level.js            10 张关卡地图与程序化建造
  tank.js             坦克（车型、四方向移动、履带动画）
  player.js           本地玩家（生命、升级、重生）
  enemies.js          敌军出生队列与 AI
  bullets.js          子弹池
  powerups.js         道具
  effects.js          墨水特效（爆炸、砖屑、焦痕）
  players.js          远端坦克渲染与状态编码
  net.js              PeerJS 大厅与传输（与涂鸦街区同源）
  hud.js              菜单 / 大厅 / 记分 DOM
  audio.js            程序化 8-bit 音乐与音效
  input.js            键盘 + 手柄
  util.js             小工具
vendor/               three.js 与 PeerJS（与涂鸦街区相同版本）
```
